## ⚡ `> WHAT IS APNA MITRA?`

**Apna Mitra** is an AI-powered healthcare companion designed to make healthcare assistance more **accessible, intelligent, simple, and user-friendly**.

The platform combines modern web technology, artificial intelligence, secure data management, and an intuitive interface to create a smarter digital healthcare experience.
