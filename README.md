## `01` — THE IDEA

> **What if healthcare technology could feel more human?**

Apna Mitra is built around a simple idea:

**Use artificial intelligence and modern technology to create a healthcare experience that is intelligent, accessible and easy to use.**

Instead of making healthcare technology complicated, Apna Mitra focuses on creating a digital companion that users can interact with naturally.
